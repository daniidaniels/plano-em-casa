# Plano em Casa · Una & Dani

App Android de emagrecimento, dieta e treino em casa (Capacitor + Health Connect).

- `www/` — o app (HTML único). É o mesmo código da versão web no Claude.
- `android/` — projeto Android gerado pelo Capacitor, com ícones, permissões e assinatura.
- `apps-script/Code.gs` — sincronização entre os celulares via planilha do Google.
- Cada push na branch `main` gera um APK assinado em **Releases** (GitHub Actions).

Desenvolvido por Daniel Santos.
